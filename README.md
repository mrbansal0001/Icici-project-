# India Micro-Wealth Affluence Index

This project computes a highly granular, pincode-level **Affluence Score** across India by aggregating 11 distinct commercial and lifestyle signals. Rather than relying on inaccurate or outdated income surveys, this model uses "footprints"—where people invest, shop, learn, and get treated—to build a real-time proxy for purchasing power.

The end product is a high-performance, agent-facing HTML dashboard designed for wealth managers, relationship managers, and sales teams to prioritize territories, find lookalike high-net-worth markets, and prospect intelligently.

## The 4 Pillars of Wealth

We aggregated 11 specific signals into four distinct pillars to calculate the Affluence Score:

1. **Financial Penetration:** Mutual Fund Distributors, Investment Advisors
2. **Commercial Vibrancy:** Corporate Hubs, Retail Branches, Private-to-Public Bank Ratio
3. **Lifestyle & Premium:** Premium Pharmacy & Retail, Golf Courses
4. **Infrastructure & Scale:** NABH Hospitals, EV Charging Points, Premium Schools, Commercial Establishments

*(Note: 20 candidate signals were evaluated, but 9 were dropped due to incomplete data, lack of authentic public sources, or insurmountable scraping resource constraints.)*

## The Dashboard

The agent dashboard (`pincode_affluence_dashboard_v2.html`) is a fully static, self-contained single-page application generated by Python. It features:
- **Explorer:** A data table to sort, filter, and search all ~19,300 pincodes.
- **Compare:** A tool to place pincodes side-by-side and compare their pillar signatures.
- **Map:** A full-screen choropleth map of India showing affluence density, with zoom-to-pincode scatter dots.
- **Watchlist:** A CRM-lite feature to save and track promising pincodes.
- **Methodology (Agent Playbook):** A beautifully styled documentary guide explaining the scoring math, the "why" behind the proxies, and 3 specific sales plays for agents.

## Core Scripts

- `build_dashboard.py`: Injects the master dataset into `dashboard_template.html` to compile the final interactive `pincode_affluence_dashboard_v2.html`.
- `affluence_score_signals.py`: The core scoring engine. It cleans the raw data, percentiles every signal to handle outliers, averages them into the 4 Pillars, and computes the final weighted Affluence Score and wealth tier (Platinum, Gold, Silver, Standard).
- `update_master_dataset.py`: Handles appending newly scraped signals into the master CSV.
- Various `scraper` scripts for individual signals (e.g., NABH, EV, Schools, etc.).

## How the Score is Calculated

1. **Signal Percentiling:** Raw counts are converted to a national percentile rank (0–100).
2. **Pillar Averaging:** Correlated signals within a pillar are averaged together.
3. **Weighted Composite:** The 4 Pillar scores are combined using equal weights (25% each), validated against PCA for variance capture.
4. **National Tiering:** Pincodes are ranked nationally: Top 2% (Platinum), Top 10% (Gold), Top 30% (Silver).

## Building the Dashboard

To regenerate the dashboard after updating the master CSV or HTML template:

```bash
python3 build_dashboard.py
```
Open `pincode_affluence_dashboard_v2.html` in any modern web browser to use the tool.
